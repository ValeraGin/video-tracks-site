Video Tracks
Политика приватности

Версия политики: 6 ноября 2026.

Что обрабатывается

Расширение воспроизводит выбранные вами видео, звуковые дорожки и субтитры на вашем устройстве. Локальный файл читается только после выбора в стандартном диалоге. Для сетевого видео браузер обращается к выбранному вами источнику и сайту, где включён плеер.

Что получает разработчик

Расширение не передаёт разработчику видео, звук, субтитры, ссылки, историю просмотра, сведения аккаунта или статистику. В расширении нет собственной телеметрии и рекламных запросов. Сайты, видеосерверы и сам браузер могут обрабатывать запросы согласно своим правилам.

Что хранится в браузере

В локальных настройках расширения сохраняются переключатель включения и явно добавленные адреса серверов — схема, хост и порт. Пути к файлам и токены в этих настройках не сохраняются. Адрес ожидающего разрешения сервера может временно храниться в storage.session. Разрешения сайтов управляются браузером. Прямая ссылка, открытая в отдельной вкладке плеера, находится в адресе этой вкладки и может быть видна обычным механизмам браузера.

Зачем нужен доступ к сайтам

На подключённых сайтах расширение может встраивать свой плеер вместо обычного видео. Сайт или сервер подключается только после отдельного разрешения. Для источника без CORS расширение добавляет необходимые заголовки ответа только в разрешённой вкладке, для её сайта-инициатора и выбранного видео либо явно настроенного сервера. Временные правила удаляются при навигации или закрытии вкладки.

Где находятся декодеры

JavaScript, WebAssembly и элементы интерфейса включены в пакет расширения. Исполняемый код не загружается с CDN. Библиотеки распространяются со своими лицензиями, доступными в разделе «О расширении».

Как удалить данные

Отозвать доступ можно в настройках расширения Chrome/Brave. Удаление расширения удаляет его локальные настройки. Для просмотра учётная запись разработчика не требуется; выбранный вами источник может требовать собственную авторизацию.

English summary

Video Tracks processes selected media locally. It does not transmit video, subtitles, URLs, browsing history or analytics to the developer. Requests go to the website and media source you choose. Enabled state and explicitly configured server origins are kept locally; a pending origin may be kept for the session. Media URLs are not saved as persistent settings. A URL opened in the player's separate tab is part of that tab's address and may be handled by normal browser history mechanisms. Host permissions are granted separately. Tab- and initiator-scoped CORS rules target the selected media or a configured server and are cleared on navigation or tab close. Code and WASM decoders are bundled; there is no remote executable code. Revoke site access in browser settings or uninstall the extension to remove local settings.
